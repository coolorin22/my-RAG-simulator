RAG harness & quality factors

▤
Data qualityAccurate, current, complete documents with useful metadata.
▣
Chunking strategyRight-sized pieces that preserve enough context.

Search qualityFind relevant chunks using vector, keyword or hybrid search.
↕
RerankingReorder retrieved results so the most useful appear first.
✧
Model & promptUse context faithfully and follow clear instructions.
▦
Evaluation & monitoringMeasure relevance, groundedness, latency, cost and failures.
PM lens: define success metrics before launch. Retrieval metrics can include Recall@K and Precision@K; answer metrics can include faithfulness, answer relevance and correctness. Also monitor latency, cost, user feedback and whether the answer should abstain when sources are insufficient.
